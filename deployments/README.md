# deployments

В каталоге лежат файлы контейнерной сборки development-инсталляции из
`docker-compose.yaml`. Запуск, состав контура, сетевые требования и ограничения
описаны в единственной пользовательской документации проекта:

- <https://graphene-ci.github.io/docs/operations/development-installation>

Production deployment в этом репозитории пока не поставляется.
