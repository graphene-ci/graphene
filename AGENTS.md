# AGENTS.md — graphene

Единственный репозиторий продукта. Всё, что было раскидано по пяти
репозиториям до переработки, живёт здесь.

## Что читать перед работой

- `VISION.md` — зачем продукт существует и для кого. Меняется редко.
- `FORM.md` — из чего он устроен, кто что выполняет и где. Здесь же
  записаны **принятые решения формы** с обоснованием и **обязательства**,
  отложенные до конкретной вехи.
- `PLAN.md` — путь до v0 вехами. Веха считается взятой, когда её
  доказательство воспроизводится на чистой машине.

Если решение противоречит `FORM.md` — сначала правится `FORM.md`, потом
код. Не наоборот и не молча.

## Раскладка

Описана в `README.md`. Одно правило важнее остальных:

**`pkg/pipeline` импортирует пользователь.** Он не имеет права тянуть
`sigs.k8s.io/controller-runtime`, `k8s.io/client-go` и облачные SDK.
Разрешено: `api/`, `pkg/agent`, `go.temporal.io/sdk`, `k8s.io/apimachinery`,
стандартная библиотека. Это проверяет `pkg/pipeline/imports_test.go`. Тест
падает — значит, зависимость поехала не туда; ослаблять список нельзя,
надо переносить код в `internal/`.

## Правила

- Go. Никаких `replace` в `go.mod`: зависимости берутся с GitHub.
- Все инструменты — в `bin/`, прибитых версий, ставятся `make configure`.
  Ни одного `latest`, ни одной глобальной установки. Версии — переменные
  в `Makefile`; их подъём — отдельный явный коммит.
- `make test` и `make lint` зелёные перед каждым push: 0 падений,
  0 issues. Где линтер неправ — исключение в `.golangci.yaml`
  **с записанной причиной**, никогда голый `//nolint`.
- Тесты вперёд кода: сначала падающий тест, потом минимальная
  реализация. Коммиты частые и мелкие.
- Коммиты — Conventional Commits (`type(scope): summary`), императив,
  строчная буква, без точки, ≤72 символа. **Никаких приписок об ИИ**
  и `Co-Authored-By`.
- Документация — текущее состояние, а не журнал изменений. Никаких
  «что нового» и «раньше было так». Изменение поведения правит
  `README.md`/`FORM.md` в том же коммите, а не позже.

## Как проверять

```sh
make configure && make test && make lint
```

Локальное окружение (k3s, Temporal, Crossplane) — `make up`, сносится
`make down`. Готовность проверяется `bin/graphene up --wait`.
